CodeAlpha Hangman Game
About the Project
This is a simple text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

The player has to guess a randomly selected word one letter at a time.

Features
Randomly selects a word from a predefined list
Allows the player to guess one letter at a time
Allows a maximum of 6 incorrect guesses
Detects repeated guesses
Displays correctly guessed letters
Displays the remaining incorrect guesses
Shows whether the player wins or loses
Technologies Used
Python
Random module
Lists
Strings
While loop
If-else statements
Console input/output
How to Run
Make sure Python is installed on your computer.
Open this project folder in VS Code.
Open the VS Code terminal.
Run the command: python hangman.py
Enter one letter at a time when prompted.
Try to guess the complete word before using all 6 incorrect guesses.
